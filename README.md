# ITM Ders Sistemi

Introduction to Management dersi için ders ders Türkçe anlatım, haftalık takip, günlük aralıklı tekrar ve teşhis. Tek dosyalık, sunucusuz bir web sayfası; telefonda da çalışır.

Canlı: https://7mtoker.github.io/itm-ders-sistemi/

- İlerleme yalnızca kullandığın tarayıcıda saklanır. Ayarlar'daki yedek metniyle başka cihaza taşınır.
- Derleme: `node arac/derle.mjs` (`index.html` ve `ITM-Ders-Sistemi.html` üretir).
- Testler: `node test/<plan|tekrar|teshis|gunluk|hoca|duman>.test.mjs`

Kişisel çalışma aracıdır; ders içeriği kursun notlarına dayanır.
